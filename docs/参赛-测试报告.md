## 二、性能测试（E6，单机 CPU 口径）

| 项 | n | p50 | p95 | max |
|---|---|---|---|---|
| 护栏 audit·普通菜谱 | 500 | **0.165ms** | 0.249ms | 1.64ms |
| 护栏 audit·违禁菜谱 | 500 | 0.247ms | 0.298ms | 0.464ms |
| 护栏 audit·长菜谱（3 倍长） | 500 | 0.412ms | 0.473ms | 0.732ms |
| RAG 混合检索全链路 | 30（8 查询轮转） | **17.4s** | 19.7s | 21.0s |

读法：
1. **护栏兜底近乎零成本**——0.2-0.5ms 的确定性审计 vs 重生成一次 LLM 调用的秒级开销，「模型生成、规则兜底」不以延迟为代价；
2. 长文本 3 倍长度仅 2.5 倍耗时，近线性非平方；
3. 检索 17s 是本机 CPU 跑 embedding + BM25 + 重排全链路的环境瓶颈，**GPU 部署的改善幅度未实测、故不写预期数字**。
- 复跑：`.venv\Scripts\python.exe benchmarks\run_perf_baseline.py`

## 三、可靠性测试

1. **回归可复跑**：506 项全量一次通过（247s），同一命令第二次执行结果一致；
2. **输入健壮性**：护栏入口对空输入有防护（`text or ""`），对非字符串输入的崩溃曾实测复现并修复，带回归用例；
3. **实验异常如实性**：E4 每轮 3-4/14 的调用失败来自本地网关 `content=null`，实验脚本与报告均如实列出，绝不并入成功分母；
4. **空返回链路查证（代码级）**：主生成节点的 3 次重试只捕获异常（5xx/连接/限流），HTTP 200 + `content=null` 不触发该重试（`agent/graph.py` L1655-1666）；下游结构化节点自带「解析失败回灌修正」自愈（L2346）。**未验证边界如实声明**：主节点收到 null 后的全链路落点未做故障注入测试，生产侧也无空屏复现报告；依项目冻结条款，在无可复现生产问题前不改动输出链路。
5. **多轮实验一致性**：护栏审计单测跨三轮演进保持 47/47，全量 506 无红，未出现「修 A 破 B」。

| 限制 | 影响 | 处置 |

## 五、结论

- **功能层**：自动化测试 506 + 38 + 47 全绿，检索 39/39、护栏两组对照 70/70 与 30/30、语境 17/17、端到端闭环 0 残留——核心行为均有可复跑证据；
- **性能层**：确定性护栏毫秒级、检索延迟如实标定本机口径；
- **可靠性层**：回归稳定、异常如实、无静默失败；对未验证的边界（空返回全链路落点）明确声明而非含糊带过。
