四、落地顺序与每步验收

  1. 先交这份户型图——你拍板房间划分，才动代码。（本文档）
  2. 加导航壳 + 打通今晚房间：四项导航可见；提问→等待→结果可跑通；刷新、前进后退稳定；成员上下文不丢。今晚的骨架（AskView → WaitCard → ResultView）已存在，这步是接上导航而不是重建。
  3. 周报房间：真实数据可展示；不足数据有明确空态；能从某顿回到今晚。
  4. 收藏房间：收藏、取消、打开条目、回今晚闭环成立。
  5. 服务房间：入口、详情、回来源链路成立；无服务时不出现假数据。

每步都必须有：页面级截图 + 导航矩阵实际走查 + 真实数据验收记录。二级房间不阻塞今晚流程。
