## 追加修复：页面不会自动刷新旧 500 错误
- **现象**：后端 500 修好后，浏览器侧栏仍显示旧 500 错误，点击「新建会话」看似没反应。

## Windows/Git Bash 运维要点
- **`pkill -9 -f <pattern>` 在 Git Bash 下确实能杀匹配进程**（连用户常驻的也一起杀了），所以不要用它做"清理测试进程"——范围太宽会误伤。
- 正确停端口方式：`netstat -ano | grep :<port>` 取 LISTENING 行最后一列的真实 Windows PID → `taskkill.exe /PID <pid> /F`。
- 注意 msys 的 `ps` 显示的 pid 与真实 Windows PID 不同，`taskkill` 必须用 `netstat` 拿到的真实 PID。
